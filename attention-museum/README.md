# 官网国际化

纯静态站点，首页、隐私政策、用户协议和 Terms of Use 均支持简体中文、繁体中文、英语、日语、韩语、法语、德语、意大利语。

## 维护与生成

- `templates/`：四个共享 HTML 模板；`{{key}}` 对应翻译资源。
- `locales/<语言>.json`：八组完整文案，每组 245 个键。含整段协议、图片说明、导航、页面元信息及演示状态。
- `assets/site.js`：语言解析、选择与记忆、首次访问的语言路由、一分钟专注演示。
- `assets/site.css`：原有视觉、多语言字体、手机导航和长单词换行。
- 根目录四个 HTML 与八个语言目录中的 32 个 HTML 是生成产物，修改模板或资源后需重新生成。

在项目根目录执行：

```sh
python3 scripts/build_web_localizations.py
python3 scripts/validate_web_localizations.py
node --test scripts/test_web_i18n.mjs
python3 -m http.server 8000 --directory web
```

发布根目录四个 HTML、八个语言目录和 `assets/` 即可，无需 Node 构建或服务端渲染。模板与资源 JSON 用于维护，运行中的网页不请求它们。

## 语言行为

顶部选择器包含八种语言和「跟随浏览器」。首次访问根页面时，顺序为有效的 `?lang=` 参数、已保存的语言、浏览器首选语言，最后回退英语。地区及脚本匹配与 App 一致，例如 `zh-TW`、`zh-HK` 选择繁体，`zh-Hans-TW` 仍选择简体。

`/fr/privacy.html` 等明确的语言地址保持其自身语言，方便分享；站内导航沿用该语言。切换时保留当前页面、其他查询参数和章节锚点。语言偏好使用浏览器本地存储，禁用存储后仍能依靠地址切换。根页面使用替换导航，避免返回时陷入重定向循环。

App 的官网协议链接使用 `privacy.html?lang=ja` 等地址，网页跳至对应的静态译文。查询参数不改变历史根路径，旧版网站尚未更新时仍能打开原页面。

没有 JavaScript 时，正文和所有协议仍完整显示，可通过语言链接阅读各译文；专注演示禁用并显示说明。每页均输出正确的 `lang`、标题、描述和八语 `hreflang`。法律条款中的英文版本和中国大陆中文版本引用指向指定语言，其他站内链接保持当前语言。
