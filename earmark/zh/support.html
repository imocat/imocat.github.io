联系我们

有问题、发现 Bug，或想提新功能？请发邮件到 hello@txxy.in。耳记由 txxy 开发。

为了更快了解问题，请附上 iPhone 与 Apple Watch 型号、iOS 与 watchOS 版本、耳记版本、实际发生的情况和你的预期。可以提供复现步骤或隐去个人信息的截图。请勿发送 API Key。我们看不到你的资料库，也无法远程取回录音。

常见问题

耳记需要订阅吗？

不需要。耳记一次性付费下载，美区 US $4.99，其他地区按当地价格定价。可选的 AI API 费用由服务商另行收取。购买与退款由 Apple 处理。

需要哪些设备？

需要运行 watchOS 26 及以上的 Apple Watch，以及配对且运行 iOS 26 及以上的 iPhone。只有手表负责全天录音；iPhone 接收音频、本机转写，并提供浏览、搜索和「问问」。

手表充电时录音停了，怎么办？

录音会在耳记手表录音会话处于活动状态时运行。手表离开充电器后，请打开手表上的耳记，检查是否仍在录音；如果已经停止，请重新开始。

为什么 iPhone 上还没有录音？

手表每 5 分钟传输一段音频，配对的 iPhone 靠近时更容易完成传输。打开 iPhone 上的耳记可帮助同步。轻点「日子」中的手表状态胶囊，或进入设置的 Apple Watch 区域，请求同步。手表不可达时，请唤醒手表并打开耳记。

怎样配置 AI？

在设置中选择 OpenAI、DeepSeek、通义千问、Kimi、MiniMax 或 OpenRouter，填入自己的 API Key 并选择模型。「问问」需要支持流式工具调用的模型。服务商的 API 访问和计费通常与面向消费者的聊天订阅分开。

不配置 AI 也能用吗？

可以。手表录音、传输、本机转写、浏览和全文搜索都不依赖 AI。「问问」和 AI 总结需要配置自己的服务商。没有 AI 时，仍可看到本地关键句和手表标记。

总结什么时候生成？

配置 AI 服务商后，自动小时摘要默认开启。在小时结束、转写完成后，会发送该小时的文字，可能消耗 API 额度。关闭开关即可停止自动请求。完整日总结始终由你主动选择生成。

iPhone 麦克风也会全天录音吗？

不会。只有按住「问问」输入框听写问题时才会使用麦克风；VoiceOver 提供开始／停止控件。语音在本机转写，不保存音频，松手发送识别出的文字，上滑可取消。每次最多 60 秒，到限后自动发送文字。

音频过期后，还能看转写吗？

可以。音频会按保留期限自动清理，默认 30 天。文字、高光、总结和对话会保留到你删除为止。引用仍可定位保留的文字，但已过期的音频无法回放。

一定要连接 Apple 健康吗？

不需要，连接完全可选且仅限读取。授权后，心率、体能训练、睡眠和步数可在耳记内显示，不会发送给 AI。你可以关闭连接，或在 Apple 设置中撤销访问权限。

中国大陆什么时候可以下载？

耳记先在中国大陆以外地区上架，完成所需 App 备案后再开放中国大陆，目前尚未公布时间。

问题排查

录音或传输卡住了

  • 确认手表上的耳记正在录音，并已允许麦克风访问。
  • 让配对的 iPhone 靠近，在两台设备上打开耳记，并等待当前 5 分钟片段结束。
  • 在「日子」的手表状态面板或设置的 Apple Watch 区域请求同步，同时检查两台设备的电量和剩余空间。

收到音频，却没有文字

  • 在 iPhone 打开耳记，查看转写状态。静音片段会有意跳过。
  • 检查设置中的转写语言。修改仅影响之后入库的片段。
  • 如果正在下载语音模型，请保持网络连接并留出足够空间，等待下载完成。转写本身在设备上完成。

AI 回答或总结失败

  • 检查服务商、HTTPS Base URL、模型、API Key、网络，以及服务商余额和限流情况。
  • 「问问」请选择支持流式工具调用的模型。消费者聊天订阅不一定包含 API 访问权限。
  • 确认当天已有转写内容。小时摘要要等到小时结束且转写完成后才会生成。
  • 排查期间可以先关闭自动小时摘要。寻求支持时，请勿附上 API Key。

语音提问无法开始

请在 iPhone 设置中允许耳记使用麦克风。收起键盘、输入框未聚焦时，长按输入区域即可听写；短按仍是打字。松手发送，上滑取消。VoiceOver 提供开始／停止控件。发送问题需要先配置 AI 服务商。

引用打不开原声了

请确认原声音频是否已超过保留期限。保留的文字仍可打开，但我们无法恢复已删除的音频。后续录音的保留时间可在设置中调整。

想清空资料库？

在设置中使用完整删除，可清除 iPhone 资料库，默认保留 API Key，也可选择一并移除。手表录音需要另外在手表上停止。操作前请阅读删除说明，删除可能无法撤销。

隐私与条款

资料库留在你自己的设备上。我们没有 App 服务器，也无法远程访问录音。可选 AI 请求直接发送到你配置的服务商。

数据处理与删除方式见隐私政策；录音责任、购买和第三方服务等事项见使用条款。
