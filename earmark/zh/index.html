04 / 开始前，你可能想知道

第一段录音前，
先聊几件小事。

关于耳记的几个日常问题。

前往支持页面
需要订阅吗？

不需要。耳记是付费下载，美区 US $4.99，一次买断；其他地区按当地 App Store 价格档定价。AI 服务商可能另行收取 API 调用费用。

一定要有 AI Key 吗？

录音、本机转写、浏览和全文搜索都不需要 AI。使用「问问」和 AI 总结时，请在设置中选择服务商，填入自己的 API Key。「问问」需要支持流式工具调用的模型。

耳记什么时候会把文字发给 AI？

提问或生成日总结时，相关文字会从 iPhone 直接发给你选的服务商。配置服务商后，「自动小时摘要」默认开启，会在每个小时结束且转写完成后发送该小时的文字。你可以随时在设置中关闭。

需要哪些设备？

需要运行 watchOS 26 及以上的 Apple Watch，以及配对且运行 iOS 26 及以上的 iPhone。全天录音由手表完成，iPhone 负责接收、转写和浏览。

为什么 iPhone 里还没收到录音？

手表以 5 分钟为单位传输音频，配对的 iPhone 靠近时更容易完成传输。打开 iPhone 上的耳记可帮助同步，也可以在手表状态面板或设置中请求同步。

中国大陆可以下载吗？

耳记先在中国大陆以外的地区上架。中国大陆将在完成所需 App 备案后开放，目前尚未公布具体时间。

可以录下别人的声音吗？

请仅在法律允许的场景录音，并取得依法需要的同意。你有责任遵守当地录音法律，尊重身边人的隐私。
