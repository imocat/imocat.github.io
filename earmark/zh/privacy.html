先说重点

你的一天，留在你手里。耳记 Earmark 由 txxy 开发。我们不运营耳记服务器，不收集、不接收、不存储你的 App 数据，也不要求注册耳记账号。

音频与转写留在你的设备上。AI 功能为可选项，使用你自己配置的服务商与 API Key，文字直接从 iPhone 发给该服务商。我们不会收到这些文字，App 也绝不会将原声音频或 Apple 健康数据发送给 AI。

本政策适用于 iPhone 与 Apple Watch 上的耳记。「本网站与支持邮件」一节另行说明静态网站访问，以及你主动发给我们的邮件。

我们不收集的数据

耳记不会将你的录音、转写、手表标记、搜索记录、AI 问答、健康信息、API Key 或设备标识符发送给我们。我们不建立用户画像，不出售你的 App 数据，也不用这些数据训练模型。

App 不包含任何统计、广告或追踪 SDK。耳记资料库没有开发者提供的云端存储，也不会通过耳记同步到 iCloud。

保存在你设备上的数据

  • 音频与传输。Apple Watch 每 5 分钟保存一段录音，通过 Apple 的 WatchConnectivity 框架将音频和时刻标记直接传到配对的 iPhone。传输完成前，手表可能保留待传录音；已传输的音频会从手表队列移除。iPhone 收到的音频保存在本地。
  • 转写与资料库。iPhone 会跳过静音片段，使用 Apple 本地语音识别完成转写。转写、时间信息、高光、本地搜索索引、总结和 AI 对话均保存在本机。录音不会上传给 txxy。
  • 麦克风与语音处理。手表录音需要麦克风权限，并由你主动开始。iPhone 仅在你按住「问问」输入框听写问题时使用麦克风；VoiceOver 提供开始／停止控件。听写在本机转写，不保存音频；松手、停止或取消时，麦克风随即关闭。发送问题时，识别出的文字才会发给你的服务商。Apple 语音模型首次使用时可能需要下载。
  • 健康数据与偏好设置。经你授权后，部分 Apple 健康信息会被读取，并且仅在耳记内显示。App 设置和 AI 连接信息保存在本地；API Key 保存在设备的 iOS 钥匙串中。

可选的第三方 AI 服务

是否配置 AI，由你决定。预设服务商包括 OpenAI、DeepSeek、通义千问、Kimi、MiniMax 和 OpenRouter。请求使用你自己的 API Key，从 iPhone 直接发送到你选择的服务商，不经过耳记服务器。

  • 问问：为回答问题，会发送问题文字、对话上下文和检索到的相关转写片段，其中包括来源时间或引用标识。请求还包含处理指令，以及设备日期、时区和首选语言等有限上下文。
  • 日总结：由你主动选择生成，发送相关转写文字。较长的一天可能分多次请求处理，再根据中间的文字摘要合并。
  • 自动小时摘要：首次配置好服务商后默认开启。每个小时结束、对应转写完成后，会自动发送该小时的转写文字，生成摘要和话题。你可以在设置中关闭。

原声音频与 Apple 健康数据从不发送给 AI。API Key 仅保存在本机不同步的钥匙串中，用于向服务商验证请求。服务商通过互联网接收请求，也可能处理你的 IP 地址等连接信息。

服务商收到的文字受其自身隐私政策、保留规则、服务条款，以及可能涉及的模型路由安排约束。我们不控制这些做法。配置前请自行阅读，避免发送你不希望交由其处理的信息。服务商、模型、Key 和自动摘要开关都由你控制；API 调用可能产生额外费用。录音、转写、浏览和搜索不需要 AI。

Apple 健康

连接 Apple 健康是可选的。授权后，耳记可以读取心率（含静息心率）、体能训练、睡眠和步数，放在一天的记录旁供你查看。耳记只申请读取权限，从不向 Apple 健康写入数据。

健康信息仅为显示而临时缓存在内存中，不加入转写搜索索引，不发送给 AI，不分享给 txxy 或其他方，不用于广告，也不会出售。耳记不会把这些信息传出 iPhone。你可以在耳记中关闭连接，也可以在 Apple 的「健康」或系统隐私设置中撤销授权。删除耳记不会删除 Apple 健康中的原始记录。

录下他人的声音

录制他人前，请取得依法需要的同意，并遵守你所在地适用的录音与隐私法律。何时、何地可以合法录音，由你负责判断。请勿在禁止录音的场所或情形下录音。

儿童

耳记不面向未满 13 岁的儿童；当地适用规定要求更高年龄时，不面向未满 16 岁的儿童。我们不会通过 App 有意收集儿童的个人信息。如果你对儿童使用耳记或发给我们的邮件有疑问，请联系 hello@txxy.in。

你的选择与数据删除

  • 录音与权限。在手表上开始或停止录音。你可以在系统设置中撤销麦克风权限，拒绝 Apple 健康访问，也可以不使用语音提问。
  • 音频保留期限。音频会在你选择的 7、14、30 或 90 天后自动清理，也可选择永久保留。默认期限为 30 天。清理随 App 维护任务执行，并非在到期瞬间立即运行。文字、高光、总结、对话及搜索索引会一直保留，直到你删除。音频清理后无法回放，但仍可阅读保留的转写。
  • 完整删除。在设置中使用完整删除功能，可清除 iPhone 上耳记的录音、转写、高光、总结、对话和搜索索引。默认保留 API Key；如需同时移除，请勾选删除 Key 的选项。手表录音由手表独立控制，如果不希望继续产生录音，请在手表上停止。
  • 卸载 App。删除 App 会移除其本地资料库。iOS 钥匙串项目可能在卸载后保留；如需一并移除 API Key，请先在完整删除时选择删除 Key。如需清除手表上的本地数据，也请移除手表 App。
  • AI 与服务商的数据。你可以关闭自动小时摘要，或移除 AI 配置，停止后续 AI 请求。删除本地内容不会删除服务商已经收到的文字；如需向其申请删除，请联系服务商或使用其提供的控制功能。

我们从未收到你的资料库，因此无法远程取回、恢复或删除其中内容。选择删除或缩短保留期限前，请自行保留重要内容。

安全

耳记使用设备本地的 App 存储，并以仅限本设备、不同步的 iOS 钥匙串保护 API Key。AI 连接必须使用 HTTPS。请及时更新设备和系统，设置设备密码，并妥善保管 API Key。

任何设备或传输方式都无法保证绝对安全。耳记不提供开发者托管的备份，删除数据可能无法撤销。我们不承诺另行提供端到端加密服务，也无法控制 AI 服务商的安全做法。

国际用户

耳记先在中国大陆以外的地区上架。App 不会将资料库发送到任何国家的耳记服务器。开启 AI 后，服务商可能在你所在国家以外的地区处理你发送的文字，并受其政策和适用法律约束。服务商由你选择，请确保合法使用。

当地强制性法律赋予你的隐私或消费者权利不受影响。你可以通过设备与耳记设置控制本地数据；如有涉及 txxy 的问题，请联系我们。

本网站与支持邮件

本静态网站与 App 分开运行，没有统计脚本、广告脚本、账号表单或追踪 Cookie。网站通过 Google Fonts 加载 Figtree 字体；浏览器会连接 Google 字体服务和网站托管服务商，对方可能收到 IP 地址、请求资源等标准连接信息，并按其基础设施政策处理。网站无法访问你的耳记资料库。

如果你主动发邮件寻求支持，我们会收到你提供的邮箱地址、邮件正文和附件，以便回复。这与 App 自动收集数据是两回事。除非你明确希望分享，请不要发送录音、健康信息或 API Key。你可以要求我们删除支持往来邮件，但适用的法定保留义务除外。

政策变更

随着耳记功能或适用要求变化，我们可能更新本政策。最新版本会发布在本页，并更新「最后更新」日期。法律要求时，我们会另行提供通知。决定启用新功能前，建议查看本页。
